Example 1: YouTube Recommendation Experiment

Repeated Measures ANOVA

Scenario: The same cohort of 100 active YouTube users rate 3 candidate recommendation algorithms (Model A: Collaborative Filtering, Model B: Deep Candidate Generator, Model C: Transformer Two-Tower) across 3 consecutive weeks.
Why Repeated Measures? Every single user is exposed to all 3 treatment conditions. Within-subject variance is extracted to remove individual user baselines, dramatically increasing statistical power.

Example 2: Google Search Ranking Experiment

2x3 Mixed ANOVA

Scenario: Search users from 3 Countries (India, USA, Brazil) [Between-Subjects Factor] each test both Old (v1) and New (v2 AI Overviews) Ranking Systems [Within-Subjects Factor].
Why Mixed ANOVA? Combines between-subject grouping (Geography) with within-subject repeated testing (Ranking Version), allowing us to measure the Country $\times$ Ranking System Interaction Effect.

Decision Science Interview Pitch: ANOVA Design Choice

"When designing tech experiments, choosing between Repeated Measures (Within-Subjects), Between-Subjects, and Mixed ANOVA depends on trade-offs between variance reduction, carryover effects, and user fatigue. In YouTube's recommendation test, we used a Within-Subjects design to subtract individual user baselines ($SS_{\text{Subject}}$), reducing residual error variance by 60%. For Google Search, a Mixed ANOVA allowed us to isolate how geographical region moderates ranking algorithm acceptance ($F_{\text{Country} \times \text{System}}$ interaction). For Google Maps, a Between-Subjects design eliminated learning bias across navigation UIs."
